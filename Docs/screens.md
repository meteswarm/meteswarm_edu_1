# screens.md — 화면 설계서

## 요금제 추천 화면

### 목적
요금제를 확인할 방식을 선택한다.

### 라우트
미정 — 자료에 경로가 명시되어 있지 않음.

### 구성 요소
- 미정 — 해당 화면의 디자인이 제공되지 않음.
- 앞에서 확인한 컴포넌트 중 어떤 것을 사용할지는 확정하지 않음.

### 상태
- 기본: 추천 방식 선택. 플로우에 자동 추천과 직접 탐색 분기가 있음.
- 로딩: 미정 — 자료에 정의 없음.
- 빈: 미정 — 자료에 정의 없음.
- 에러: 미정 — 자료에 정의 없음.

### 이동
- 들어오는 곳: 서비스 시작.
- 나가는 곳:
  - 자동 추천 → 맞춤 요금제 추천 결과.
  - 직접 탐색 → 전체 요금제 목록.

## 맞춤 요금제 추천 결과

### 목적
자동 추천된 요금제를 확인하고 상세 화면으로 이동한다.

### 라우트
미정 — 자료에 경로가 명시되어 있지 않음.

### 구성 요소
- 미정 — 해당 화면의 디자인이 제공되지 않음.
- 추천 목록의 구성, 추천 기준, 표시 항목은 확정하지 않음.

### 상태
- 기본: 자동 추천 결과를 확인하는 단계.
- 로딩: 미정 — 자료에 정의 없음.
- 빈: 미정 — 추천 결과가 없을 때의 처리 정의 없음.
- 에러: 미정 — 추천 실패 시 처리 정의 없음.

### 이동
- 들어오는 곳:
  - 요금제 추천 화면의 자동 추천 분기.
  - 요금제 상세 페이지의 요금제 재선택 흐름.
- 나가는 곳: 요금제 선택 → 요금제 상세 페이지.

## 전체 요금제 목록

### 목적
전체 요금제의 가격과 혜택을 확인하고 상세 화면으로 이동한다.

### 라우트
미정 — 자료에 경로가 명시되어 있지 않음.

### 구성 요소
- Header
  - Type=root
  - 디자인의 화면 제목: 요금제 목록
  - 내부 컴포넌트: Logo
- FilterChip
  - 전체: State=selected
  - 베이직, 스탠다드, 프리미엄: State=default
  - 필터별 결과와 전환 방식은 미정.
- 신규: 목록 안내
  - 현재 일반 프레임·텍스트로 구성되어 있으며 컴포넌트 원본은 확인되지 않음.
  - 나에게 맞는 요금제를 선택하세요
  - 요금제별 혜택을 확인한 후 구독할 수 있어요.
- Card/Plan
  - State=default
  - 베이직: 월 5,900원 / 월 10회 이용 · 기본 기능 제공
  - 스탠다드: 월 9,900원 / 월 30회 이용 · 기본 기능 + 이용 기록
  - 프리미엄: 월 14,900원 / 무제한 이용 · 기본 기능 + 이용 기록
  - 내부 컴포넌트: Tag
    - 표시 문구: 추천
  - 내부 컴포넌트: Button
    - Type=Secondary, Size=sm, State=Default
    - 버튼 문구: 요금제 보기
- 신규: 요금 안내 문구
  - 현재 일반 텍스트이며 컴포넌트 원본은 확인되지 않음.
  - 모든 요금은 부가세 포함 금액입니다.

### 상태
- 기본: 전체 필터가 선택되어 있으며 요금제 카드 3개가 표시됨.
- 로딩: 미정 — 자료에 정의 없음.
- 빈: 미정 — 목록이나 필터 결과가 없을 때의 처리 정의 없음.
- 에러: 미정 — 목록 조회 실패 시 처리 정의 없음.

### 이동
- 들어오는 곳:
  - 요금제 추천 화면의 직접 탐색 분기.
  - 요금제 상세 페이지의 요금제 재선택 흐름.
- 나가는 곳: 요금제 보기 → 요금제 상세 페이지.

## 요금제 상세 페이지

### 목적
선택한 요금제의 가격, 혜택, 조건을 확인하고 구독 신청 여부를 결정한다.

### 라우트
미정 — 자료에 경로가 명시되어 있지 않음.

### 구성 요소
- Header
  - Type=default
  - 디자인의 화면 제목: 요금제 상세
  - 내부 컴포넌트: icon/arrowLeft
- Card/Price
  - 파일에서 사용 중인 외부 원본 참조 컴포넌트
  - 디자인 예시: 스탠다드
  - 월 9,900원
  - 부가세 포함 · 매월 정기 구독
- List/Row
  - Type=default
  - 제공 혜택:
    - 이용 횟수: 월 30회
    - 기본 기능: 제공
    - 이용 기록: 확인 가능
- 신규: 구독 안내
  - 현재 일반 프레임·텍스트로 구성되어 있으며 컴포넌트 원본은 확인되지 않음.
  - 이용 기간: 신청일부터 1개월
  - 갱신 주기: 매월 자동 갱신
  - 이용 횟수는 매월 새로 제공되며, 남은 횟수는 다음 달로 이월되지 않습니다.
- Button
  - 구독 신청: Type=Primary, Size=xl, State=Default
  - 뒤로: Type=Secondary, Size=xl, State=Default
  - 디자인의 하단 영역은 일반 프레임이며 BottomCTA 인스턴스는 아님.

### 상태
- 기본: 선택한 요금제 정보를 확인함. 제공된 디자인은 스탠다드 요금제 예시임.
- 로딩: 미정 — 자료에 정의 없음.
- 빈: 미정 — 요금제 정보가 없을 때의 처리 정의 없음.
- 에러: 미정 — 상세 조회 실패 시 처리 정의 없음.

### 이동
- 들어오는 곳: 맞춤 요금제 추천 결과 또는 전체 요금제 목록.
- 나가는 곳:
  - 신청하기 선택 → 로그인 상태 확인.
  - 비로그인 → 로그인 / 회원가입 화면.
  - 로그인 상태 → 신청 폼 화면.
  - 요금제 재선택 → 추천 결과 또는 전체 목록의 선택 흐름으로 복귀.
  - 디자인에는 뒤로 버튼이 있으나 복귀 대상 결정 규칙은 미정.

## 로그인 / 회원가입 화면

### 목적
비로그인 사용자가 구독 신청을 진행할 수 있도록 로그인 또는 회원가입을 진행한다.

### 라우트
미정 — 자료에 경로가 명시되어 있지 않음.

### 구성 요소
- 미정 — 해당 화면의 디자인이 제공되지 않음.
- 로그인 방식, 회원가입 항목, 버튼, 안내 문구는 확정하지 않음.

### 상태
- 기본: 비로그인 사용자가 로그인 / 회원가입 화면에 진입함.
- 로딩: 미정 — 자료에 정의 없음.
- 빈: 미정 — 입력값이 없을 때의 처리 정의 없음.
- 에러: 미정 — 로그인 또는 회원가입 실패 시 처리 정의 없음.

### 이동
- 들어오는 곳: 요금제 상세 페이지에서 신청하기 선택 후 비로그인으로 확인된 경우.
- 나가는 곳: 로그인 완료 → 신청 폼 화면.

## 신청 폼 화면

### 목적
구독 신청에 필요한 개인정보와 결제 정보를 입력하고 약관에 동의한다.

### 라우트
미정 — 자료에 경로가 명시되어 있지 않음.

### 구성 요소
- Header
  - Type=default
  - 디자인의 화면 제목: 구독 신청
  - 내부 컴포넌트: icon/arrowLeft
- List/Row
  - Type=default
  - 신청 내용:
    - 요금제: 스탠다드
    - 월 요금: 9,900원 (부가세 포함)
    - 제공 혜택: 월 30회 이용 / 기본 기능 + 이용 기록
    - 이용 시작: 신청 완료 후 바로 이용
- Input
  - 디자인에서 사용된 변형: State=default
  - 이름 표시값: 김민수
  - 이메일 표시값: minsu@example.com
  - 위 두 항목은 제공된 디자인에서 확인되는 입력란임.
  - 플로우의 개인정보 입력 항목 전체와 디자인의 일치 여부는 확인 필요.
- 신규: 신청 안내 문구
  - 현재 일반 텍스트이며 컴포넌트 원본은 확인되지 않음.
  - 신청 내용을 확인해 주세요.
  - 구독은 신청일부터 매월 자동 갱신됩니다.
- Button
  - 신청: Type=Primary, Size=xl, State=Default
  - 취소: Type=Secondary, Size=xl, State=Default
  - 디자인의 하단 영역은 일반 프레임이며 BottomCTA 인스턴스는 아님.
- 결제 정보 입력 영역: 미정 — 플로우에는 있으나 해당 UI 디자인이 제공되지 않음.
- 약관 동의 영역: 미정 — 플로우에는 있으나 해당 UI 디자인이 제공되지 않음.
- 오류 안내 영역: 미정 — 플로우에는 오류 안내 메시지가 있으나 해당 UI 디자인이 제공되지 않음.

### 상태
- 기본:
  - 플로우 순서: 개인정보 입력 → 결제 정보 입력 → 약관 동의 → 입력 정보 검증.
  - 제공된 디자인에는 신청 내용과 이름·이메일 입력란만 확인됨.
  - 단계별 화면 분리나 전환 UI는 정의되어 있지 않아 하나의 신청 폼으로 정리함.
- 로딩: 미정 — 검증 중 표시 및 버튼 상태 정의 없음.
- 빈: 미정 — 미입력 시 표시 및 진행 가능 조건 정의 없음.
- 에러:
  - 입력 정보 검증에서 오류가 발견되면 오류 안내 메시지를 표시하고 입력을 수정하는 흐름으로 복귀.
  - 오류 문구, 표시 위치, 항목별 검증 조건은 미정.

### 이동
- 들어오는 곳:
  - 로그인 상태인 사용자의 요금제 상세 페이지 신청하기 선택.
  - 로그인 / 회원가입 화면의 로그인 완료.
  - 신청 확인 화면의 수정하기.
- 나가는 곳:
  - 입력 정보 검증 통과 → 신청 확인 화면.
  - 검증 오류 → 오류 안내 후 신청 폼의 입력 수정 흐름으로 복귀.
  - 디자인에는 신청·취소 버튼이 있으나 전체 플로우에서 각 버튼의 정확한 연결과 취소 목적지는 미정.
  - 신청 버튼에서 신청 완료 화면으로 바로 이동한다고 확정하지 않음.

## 신청 확인 화면

### 목적
입력한 신청 내용을 최종 확인하고 제출 여부를 결정한다.

### 라우트
미정 — 자료에 경로가 명시되어 있지 않음.

### 구성 요소
- 미정 — 해당 화면의 디자인이 제공되지 않음.
- 입력 내용 최종 확인과 수정하기, 최종 제출은 플로우에서 확인됨.
- 표시할 내역의 구체적인 항목과 사용할 컴포넌트는 확정하지 않음.

### 상태
- 기본: 검증을 통과한 입력 내용을 최종 확인하는 단계.
- 로딩:
  - 최종 제출 후 신청 데이터 저장과 신청 완료 알림 발송이 이어짐.
  - 처리 중 표시 방식은 미정.
- 빈: 미정 — 자료에 정의 없음.
- 에러: 미정 — 제출·저장·알림 발송 실패 시 처리 정의 없음.

### 이동
- 들어오는 곳: 신청 폼 화면의 입력 정보 검증 통과.
- 나가는 곳:
  - 수정하기 → 신청 폼 화면.
  - 최종 제출 → 신청 데이터 저장 → 신청 완료 알림 발송 → 신청 완료 화면.

## 신청 완료 화면

### 목적
신청 접수 완료 여부와 신청 내역을 확인한다.

### 라우트
미정 — 자료에 경로가 명시되어 있지 않음.

### 구성 요소
- Header
  - Type=default
  - 디자인의 화면 제목: 신청 완료
  - 내부 컴포넌트: icon/arrowLeft
- icon/doneMark
  - 내부 컴포넌트: icon/check
- 신규: 완료 메시지
  - 현재 일반 프레임·텍스트로 구성되어 있으며 컴포넌트 원본은 확인되지 않음.
  - 구독 신청이 완료됐어요
  - 개통 안내는 문자로 보내드려요
- List/Row
  - Type=default
  - 디자인의 신청 내역 예시:
    - 신청 번호: 2026-1013-0024
    - 요금제: 넉넉 무제한
    - 월 요금: 85,000원
    - 신청 일시: 10월 13일 14:02
    - 신청자: 김*플 · 010-****-5678
- BottomCTA
  - Layout=single
  - 내부 컴포넌트: Button
    - Type=Primary, Size=xl, State=Default
    - 버튼 문구: 요금제 더 보기

### 상태
- 기본:
  - 플로우상 신청 데이터 저장과 신청 완료 알림 발송을 거쳐 도달함.
  - 완료 메시지와 신청 내역을 표시함.
  - 확인 필요: 디자인의 요금제·금액·신청자 예시는 신청 폼 화면과 일치하지 않음. 원문을 유지했으며 실제 연결 데이터는 확인 필요.
  - 확인 필요: 플로우의 신청 완료 알림과 디자인의 개통 안내 문자의 관계 및 발송 채널은 확정하지 않음.
- 로딩: 미정 — 자료에 정의 없음.
- 빈: 미정 — 신청 내역이 없을 때의 처리 정의 없음.
- 에러: 미정 — 자료에 정의 없음.

### 이동
- 들어오는 곳: 신청 확인 화면의 최종 제출 후 데이터 저장 및 알림 발송 흐름.
- 나가는 곳:
  - 전체 플로우의 종료 지점.
  - 디자인의 요금제 더 보기 버튼과 헤더 뒤로 아이콘의 이동 목적지는 플로우에 정의되어 있지 않음.
