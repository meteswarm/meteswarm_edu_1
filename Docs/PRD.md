## 1. 배경과 문제

고객은 세 가지 순간에 요금제를 바꾸려고 한다. **[확정]**
1. 휴대폰을 살 때 고가 요금제로 받은 혜택의 **유지 기간이 끝났을 때**
2. **사용 패턴이 바뀌거나** 사용량이 늘거나 줄었을 때
3. **약정이 끝나** 휴대폰을 새로 사거나 바꿀 때

고객이 원하는 것은 **요금 추가 할인**, 또는 **자신에게 최적화된 요금제**다. 그런데 다음 지점에서 막힌다.
- 지금 요금제가 이익인지 판단하기 어렵다. 판단 기준은 월 청구 금액을 놓고 정액제와 종량제를 비교하는 것이다.
- 미납·체납 이력이 있는 고객은 사용량보다 **요금 상한액**이 중요한데, 이 기준으로 고르기 어렵다.
- 약정이 남아 있으면 **위약금·할인 반환금**이 생긴다. 금액은 결합, 제휴카드, 혜택, 할인코드, 미납요금 등에 따라 달라져서 미리 알기 어렵다.
- 대안인 **펜딩 재약정**은 상담을 거쳐야 한다.

## 2. 목표와 성공 지표

| # | 목표 |
|---|---|
| G1 | 최근 3개월 이용 데이터를 근거로, 고객이 **이익이 되는 요금제를 스스로 판단**하게 한다 |
| G2 | 고객이 정한 **상한액 안에서** 통신 요금제와 구독 요금제 조합을 추천한다 |
| G3 | 변경하기 전에 **예상 위약금·반환금**을 보여 주고, 정확한 확인이 필요하면 **상담사에게 바로 연결**한다 |
| G4 | 통신 요금제 변경과 구독 요금제 가입을 **한 번에 온라인으로 신청**하게 한다 |

성공 지표 **[가정 — 목표 수치 미정]**

| 지표 | 정의 |
|---|---|
| 신청 전환율 | 1번 화면 진입 대비 5번 화면 도달 비율 |
| 예상 비용 확인 후 이탈률 | 3번 화면에서 예상 비용을 본 뒤 나간 비율 |
| 상담 연결률 | 3·4번 화면에서 [상담사 연결]을 누른 비율 |
| 상한액 준수율 | 신청한 조합의 월 요금이 고객 상한액 이하인 비율 |

## 3. 용어 (요약)

| 용어 | 정의 |
|---|---|
| 요금제 | 상위 개념. **통신 요금제**와 **구독 요금제**를 모두 포함하고, 둘 다 "가입"하는 상품 **[확정]** |
| 통신 요금제 | 데이터·통화·문자를 제공. 회선당 1개 **[가정 A9]** |
| 구독 요금제 | 요금제의 한 종류. **약정이 없고 언제든 해지 가능** **[확정]**. 통신 요금제에 더해 여러 개 가입 가능 **[가정 A9]** |
| 변경 / 가입 | "변경"은 통신 요금제에만, 구독 요금제는 "가입"이라고 쓴다 |
| 일반 요금 | **종량제** (쓴 만큼 내는 방식) **[확정]** |
| 월 청구 금액 | **최근 3개월 청구 금액 평균** **[확정]** |
| 요금 상한액 | 고객이 넘지 않기를 원하는 월 요금 한도. 구독 요금제 요금 포함 **[확정]** |
| 혜택 유지 기간 | 휴대폰을 살 때 받은 혜택 때문에 고가 요금제를 유지해야 하는 기간 **[확정]** |
| 예상 변경 비용 | **금일 기준** API로 계산한 1차 위약금·할인 반환금 **[확정]** |
| 펜딩 | 할인 혜택·추가 할인 조건을 걸고 연장 계약(재약정)하는 제도. 상담사 연결로만 처리 **[확정]** |

## 4. 대상 사용자

로그인(본인 인증)한 **기존 고객**만 이용한다. **[가정 A4]**

| 사용자 | 목표 |
|---|---|
| 혜택 유지 기간이 끝난 고객 | 지금 요금제가 맞는지 판단하고, 더 저렴한 요금제로 변경 |
| 사용 패턴이 바뀐 고객 | 정액제와 종량제를 비교해 요금 할인 |
| 미납·체납 이력이 있는 고객 | 상한액을 넘지 않는 요금제 선택 |
| 약정 기간이 남은 고객 | 예상 비용 확인 또는 펜딩 상담으로 손해 없이 변경 |
| 상담사 (서비스 밖) | 정확한 금액 안내, 펜딩 재약정 처리 |

## 6. 범위

**포함**
- 5개 화면: 내 이용 현황 → 맞춤 추천 결과 → 요금제 상세 + 예상 변경 비용 → 변경 신청 → 신청 완료
- 통신 요금제 **변경** + 구독 요금제 **가입**을 한 번에 신청 **[가정 A3]**
- 금일 기준 예상 위약금·반환금 조회 (API)
- [상담사 연결] 버튼 → 바로 전화 연결 (3·4번 화면)

**제외**
- 펜딩 재약정 온라인 신청 (상담사 연결로만 처리)
- 타사 번호이동 안내·처리
- 휴대폰 구매·기기 변경
- 신규 가입·회원가입 **[가정 A4]**
- 정확한 위약금·반환금 확정 (1차 예상 금액만 제공)
- 구독 요금제 해지 **[가정 A12]**
- 상담 예약·콜백·채팅
